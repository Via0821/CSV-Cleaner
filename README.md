# CSV Cleaner

CSV の表記ゆれと重複を整えて、きれいな CSV を書き出すコマンドラインツールです。

```console
$ csv-cleaner examples/messy_contacts.csv cleaned.csv
クリーニング結果
  読み込み行数: 12 行
  出力行数: 10 行
  重複削除: 2 行
  変更箇所: 25 件
    空白の整形: 5 件
    メールアドレス: 6 件
    電話番号: 9 件
    欠損値の統一: 5 件
  警告: 2 件
    7行目: 「メールアドレス」の形式が正しくありません (ito.ken@example)
    8行目: 「電話番号」の形式が正しくありません (0312)
```

## なぜ作ったか

人が手で入力した CSV には、同じ内容なのに書き方が違う値が必ず混ざります。
前後に空白が入っている氏名、大文字で登録されたメールアドレス、ハイフンの位置がばらばらな電話番号、
「-」や「N/A」で埋められた空欄。こうした値が混ざったままだと、名寄せも集計も重複の判定も正しく行えません。

表計算ソフトで 1 件ずつ直す作業は時間がかかるうえ、見落としも起きます。
同じ整形を毎回繰り返すのであれば、ルールをコードに書いて自動化したほうが確実です。
CSV Cleaner はその整形処理をまとめたツールです。

## 主な機能

- **空白の整形** — 前後の空白を削除し、値の途中の連続した空白を 1 つにまとめます（全角スペースにも対応）
- **欠損値の統一** — `-` `N/A` `なし` などのプレースホルダーを空のセルに揃えます
- **メールアドレスの正規化** — 小文字に統一し、全角文字・空白・`mailto:` などを取り除きます
- **電話番号の正規化** — 区切り記号を取り除き、全角数字と国際表記（`+81`）を国内表記に揃えます
- **重複行の検出** — 整形したあとに内容が一致する行を取り除きます
- **形式の検証** — 不正なメールアドレスや電話番号を、行番号付きの警告として報告します
- **処理結果の表示** — 読み込み件数・出力件数・変更箇所の内訳を実行後に表示します

整形したあとに重複を判定するため、「前後の空白だけが違う行」や「メールアドレスの大文字小文字だけが違う行」も
同じ行として検出できます。

## 動作環境

- Ruby 3.1 以上（開発・動作確認は 3.4.11）
- 入力は UTF-8（BOM 付きも可）でヘッダー行のある CSV

実行に必要なのは Ruby 同梱の `csv` のみです。テストの実行に `minitest` と `rake` を使います。

## インストール

```console
$ git clone https://github.com/Via0821/CSV-Cleaner.git
$ cd CSV-Cleaner
$ bundle install
```

`bin/csv-cleaner` をそのまま実行できます。

```console
$ ./bin/csv-cleaner --version
csv-cleaner 0.1.0
```

どのディレクトリからでも使いたい場合は、`bin` を `PATH` に追加するか、シンボリックリンクを置いてください。

## 使い方

```console
$ csv-cleaner [オプション] <入力ファイル> <出力ファイル>
```

| オプション | 説明 |
| --- | --- |
| `-f`, `--force` | 出力ファイルが既にあっても上書きする |
| `-q`, `--quiet` | 処理結果の表示を省略する |
| `-h`, `--help` | ヘルプを表示する |
| `-v`, `--version` | バージョンを表示する |

既存のファイルを誤って消さないよう、出力先にファイルがある場合は `--force` を指定しない限り中断します。
入力ファイルと同じパスを出力先に指定することもできません。

終了ステータスは、正常終了が `0`、処理中のエラーが `1`、コマンドの指定誤りが `2` です。

## 入出力の例

`examples/messy_contacts.csv` に、よくある問題を詰め込んだサンプルを置いてあります。

入力（抜粋）:

```csv
氏名,メールアドレス,電話番号,会社名,備考
  田中 太郎  ,TANAKA.Taro@Example.com ,090-1234-5678,株式会社サンプル,
田中　太郎,tanaka.taro@example.com,09012345678,株式会社サンプル,-
佐藤 花子,SATO_HANAKO@example.CO.JP,+81 80-9876-5432,サンプル商事,  要確認
鈴木 一郎,mailto:suzuki@example.jp,０９０−１１１１−２２２２,,なし
```

出力（抜粋）:

```csv
氏名,メールアドレス,電話番号,会社名,備考
田中 太郎,tanaka.taro@example.com,09012345678,株式会社サンプル,
佐藤 花子,sato_hanako@example.co.jp,08098765432,サンプル商事,要確認
鈴木 一郎,suzuki@example.jp,09011112222,,
```

1 行目と 2 行目は、全角スペースと空白の有無だけが違う同じ人のデータです。
整形後に内容が一致するため、2 行目は重複として取り除かれます。

## クリーニングルール

| ルール | 対象の列 | 内容 |
| --- | --- | --- |
| 空白の整形 | すべて | 前後の空白を削除し、連続した空白を半角スペース 1 つにまとめる |
| 欠損値の統一 | すべて | `-` `--` `ー` `N/A` `NULL` `なし` `無し` `不明` などを空のセルにする |
| メールアドレス | 列名に `mail` / `メール` を含む列 | 小文字化、全角→半角、空白の削除、`mailto:` と `<>` の除去 |
| 電話番号 | 列名に `phone` / `tel` / `電話` / `携帯` などを含む列 | 全角→半角、記号の削除、`+81` から始まる番号を `0` 始まりに変換 |

電話番号は `09012345678` のような区切り記号のない形に統一します。
市外局番の桁数は地域によって異なり、ハイフンを正しい位置に入れるには市外局番表が必要になるため、
初期版では表記ゆれを確実に吸収することを優先しました。

値の形式が正しいかどうかの判定はクリーニングとは分けています。
機械的に直せない値（`ito.ken@example` のような不完全なメールアドレスなど）は勝手に書き換えず、
警告として報告したうえで、そのまま出力に残します。削除するかどうかは人が判断すべき内容だからです。

## テスト

```console
$ bundle exec rake test
```

ルールごとの単体テストから、サンプルデータを実際に処理する結合テストまで含めて 96 件あります。
新しいルールを追加するときは、`test/rules/` に同じ形式のテストを追加してください。

## プロジェクト構成

```text
bin/csv-cleaner                 実行ファイル
lib/csv_cleaner/
  cli.rb                        引数の解釈とエラー表示
  reader.rb / writer.rb         CSV の読み書き
  table.rb                      ヘッダーとデータ行を持つ値オブジェクト
  processor.rb                  整形 → 検証 → 重複除去の流れ
  row_cleaner.rb                1 行に対してルールを適用する
  rules/                        クリーニングルール（1 ファイル 1 ルール）
  validator.rb                  整形後の値の形式チェック
  duplicate_detector.rb         重複行の検出
  report.rb                     処理結果の集計と表示
examples/messy_contacts.csv     動作確認用のサンプルデータ
test/                           テスト
```

ルールは `applies_to?(header)` と `call(value)` に応答するオブジェクトです。
新しいルールを追加するときは、`lib/csv_cleaner/rules/` にクラスを 1 つ作り、
`RowCleaner.default_rules` に並べるだけで有効になります。

## 今後の改善予定

- クリーニングルールの追加（郵便番号、氏名の全角半角、日付の書式など）
- 設定ファイルでルールの有効・無効を切り替えられるようにする
- 重複判定に使う列を指定できるようにする（メールアドレスだけで判定するなど）
- 市外局番表を使った、ハイフン付きの電話番号の整形
- 処理結果を JSON や Markdown のレポートとして保存する
- JSON ファイルの入出力に対応する
- 大きなファイルを 1 行ずつ処理するストリーミング対応
